# Davide Di Matteo — Security & Research

Personal cybersecurity portfolio, served directly by GitHub Pages at https://dingo97.github.io/.

## Structure

- `index.html`: homepage and native HTML project disclosures.
- `assets/site.css`, `assets/sections.css`: shared design and homepage sections.
- `assets/site.js`: optional navigation and stored accent preference (`ddm-theme`).
- `assets/htb.js`: Hack The Box rendering and request fallback.
- `assets/features.js`, `assets/features.css`: optional command navigation and the interactive CVE explainer.
- `assets/history.js`, `htb-history.json`: independent HTB history presentation and daily snapshots.
- `research/CVE-2026-20516/index.html`: original research article with a three-stage trust-boundary explainer.
- `research/linux-antimalware/index.html`: retrospective case study from the original 2022 thesis.
- `it/`: complete, pre-rendered Italian versions of all three pages, generated by `scripts/build-locales.cjs`.
- `cv.tex` (Italian), `cv-en.tex` (English), `scripts/build-cv.py`: Harvard-style LaTeX CVs and compiler wrapper for both public PDFs.
- `assets/og.png`: generated social-sharing cover.

The public site needs **no build step and no runtime packages**. From this directory, `python -m http.server 4173 --bind 127.0.0.1` starts a local preview.

## Hack The Box contract

`.github/workflows/update-htb.yml` is the existing scheduled job. It uses the repository's `HTB_TOKEN` secret and updates the root `htb-data.json`. Its API collection code, schedule and existing JSON schema are preserved. An additive step records daily history in a separate file.

The English homepage fetches `htb-data.json?v=<timestamp>` from the same directory; the Italian homepage uses `../htb-data.json?v=<timestamp>`. Profile statistics, up to eight machines, and the latest eight combined challenges/Sherlocks are rendered from that response. `recentSherlocks` remains optional for compatibility with older snapshots. Difficulty aliases are normalized, external strings are inserted as text, and zero counts are preserved.

If the response is unavailable, malformed, or takes longer than eight seconds, an embedded snapshot is displayed with its original update date and an explicit fallback label. The snapshot is a fallback only; every page load requests the current JSON. To refresh it, replace `HTB_FALLBACK` in `assets/htb.js` with a verified copy of `htb-data.json`.

Keep `assets/htb.js` and `htb-data.json` at their current paths. Deploying only `index.html` is insufficient: publish the complete repository.

## Daily history

After a successful data fetch, `scripts/record-htb-history.cjs` reads the existing JSON and upserts the latest snapshot per UTC date into `htb-history.json`. The date comes from `htb-data.json.updated`. Reruns do not create duplicate days, missing numeric metrics remain `null`, and malformed existing history is rejected rather than discarded. The history step uses `continue-on-error` so it cannot prevent fresh profile data from being committed.

The browser loads history independently of the current statistics. One recorded day produces a table and a clear first-snapshot message; the interactive chart appears with the second date. It shows up to 30 recorded dates, with no estimated missing days or invented earlier activity. History began on 11 September 2026.

## Languages and navigation

English HTML files are the source pages. Italian pages are committed static HTML, so language navigation and article reading work without JavaScript. Both languages include reciprocal `hreflang` links and separate canonical URLs. Code snippets are preserved verbatim.

To edit translated prose, update the corresponding entries in `content/translations/en.*.json` and `it.*.json`, then run `npm run build:locales`. For new source text, `node scripts/build-locales.cjs --extract` refreshes English segment lists; align the Italian entries by their matching English text before building. The builder rejects missing translations. Do not edit generated Italian HTML directly.

The optional terminal opens with its header button or Ctrl/Cmd+K. It supports `help`, `whoami`, `research`, `thesis`, `cve`, `projects`, `htb`, `cv`, `contact`, `theme`, `clear` and `exit`, plus command history and completion. These are portfolio navigation actions. Native dialog handling supplies keyboard focus management; normal links remain available when dialog support is absent.

The CVE explainer is progressively enhanced: all three explanations are readable without JavaScript. Its stages preserve the distinction between the documented ADB reproduction and an untested ordinary-app reproduction, and do not imply a root or system shell.

## CV and thesis sources

The CVs retain the original Harvard template: Times typography, a centered heading, ruled sections, and the original education/experience/projects/skills structure. Editable sources are `cv.tex` in Italian and `cv-en.tex` in English. Both retain the existing projects and skills, with ADR experience and CVE-2026-20516 added and Leonardo's end date updated to February 2026.

Run `python scripts/build-cv.py` with Tectonic or pdfLaTeX on `PATH`; `--engine /path/to/tectonic` accepts an explicit executable. The script uses only Python's standard library, compiles both documents in a temporary directory and rejects text overflow, missing fonts/glyphs or a result longer than one page before replacing either public PDF. Both LaTeX files are self-contained and can also be compiled in Overleaf. Tectonic downloads its TeX packages on first use.

The public files remain `CV_Davide_Di_Matteo.pdf` in English and `CV_Davide_Di_Matteo_IT.pdf` in Italian, so existing download links remain valid. Each CV is one US Letter page, matching the original template. Visually inspect both PDFs after editing. The former JSON/ReportLab source has been replaced to avoid regenerating the discarded design.

The thesis case study summarizes _Analisi di sicurezza e capacità dei software Anti Malware su Linux_, Davide Di Matteo, University of Rome Tor Vergata, 28 October 2022. The matrix transcribes the historical Chapter 4 results, including the Sophos/PyInstaller and Avast/injection exceptions. The original archive, experimental malware sources and private materials are not included in this repository.

## Checks

Node.js 20+ is needed only for development checks:

```sh
npm ci
npm run check
```

Tests exercise the real JSON, legacy data, merged challenge/Sherlock ordering, empty or malformed data, HTML injection, failed requests and timeouts, daily snapshot preservation, chart interaction, terminal keyboard behaviour, localized downloads, all six pages' links and metadata, thesis matrix accuracy, and the CVE explainer. These are DOM and unit checks, not browser rendering tests.
